# Code Compete

A real-time competitive coding platform that brings the thrill of TypeRacer to LeetCode-style problems.
Challenge other developers in live coding battles, improve your problem-solving speed, and track your progression.

## Features

- [ ] Rankings
- [ ] Safe Code Executions
- [ ] Elo Based Matching
- [ ] VSC Extension
- [ ] Battle Royale Mode (Last Person to Submit Gets Kicked)
